הסמסטרון

אפליקציה קטנה שזוכרת בשבילך אילו הרצאות ותרגולים כבר עשית, מה עוד צריך להשלים, ומתי ההגשות והבחינות — בכל הקורסים של סמסטר א׳ תשפ״ז.

1 הרעיון

בכל קורס יש כמה קבוצות הרצאה ותרגול שמלמדות את אותו חומר בזמנים שונים. האפליקציה יודעת את המערכת של כולן, ולכן ברגע שהרצאה או תרגול התקיימו בקבוצה כלשהי — יש כבר הקלטה, והיא מופיעה אצלך כ"להשלים". מה שעוד לא התקיים בשום קבוצה לא מופיע בכלל, כדי שלא יהיה רעש.

אחרי שהלכת לשיעור או צפית בהקלטה — לוחצים ✓ סיימתי, וזהו.

💡 הקורסים והקבוצות כבר מוגדרים באפליקציה — הסתברות, גלים, מבוא להנדסת חשמל, מבני נתונים ו-C/C++ — כולל שינויי כיתות וביטולים שמתפרסמים במהלך הסמסטר. לא צריך להגדיר כלום.

2 התקנה (פעם אחת בכל מכשיר)

זו אפליקציית אינטרנט — לא צריך חנות. פותחים את הכתובת ומוסיפים אותה כאפליקציה:

akivamprager.github.io/semester-tracker

📱 טלפון וטאבלט אנדרואיד

  1. לפתוח את הכתובת ב-Chrome.
  2. תפריט ⋮ ← התקנת אפליקציה (או "הוספה למסך הבית").
  3. מעכשיו פותחים מהאייקון "הסמסטרון".

📲 אייפד / אייפון

  1. לפתוח את הכתובת ב-Safari (או Chrome).
  2. כפתור שתף (ריבוע עם חץ) ← הוסף למסך הבית.
  3. לפתוח מהאייקון — רק כך עובדות התראות ומספר על האייקון (iPadOS/iOS 16.4 ומעלה).

💻 מחשב Windows

  1. לפתוח את הכתובת ב-Chrome או Edge.
  2. ללחוץ על אייקון ההתקנה בשורת הכתובת (מסך עם חץ) ← התקנה. ב-Edge: ⋯ ← אפליקציות ← "התקן אתר זה כאפליקציה".
  3. האפליקציה תופיע בתפריט התחל ואפשר להצמיד לשורת המשימות.
⚠️ ההתקדמות נשמרת בכל מכשיר בנפרד. כדי שמה שסימנת בטלפון יופיע גם בטאבלט ובמחשב — מחברים סנכרון (5 דקות, פעם אחת).

3 לשונית "לעשות" — מה נשאר להשלים

6 לשונית "בחינות ומידע"

לכל קורס: כמה כבר השלמת, מועדי הבחינות והבחנים, נהלי הקורס בקצרה (הרכב ציון, כללי הגשה, AI וכו׳), ובמבני נתונים — הנושא של כל הרצאה ותרגול.

7 סנכרון בין הטלפון, הטאבלט והמחשב

הסנכרון שומר את ההתקדמות שלך בענן (בחשבון GitHub פרטי שלך — חינם), כך שאותו מצב מופיע בכל המכשירים וגם לא הולך לאיבוד אם מוחקים את האפליקציה.

  1. להירשם ל-GitHub (חינם, דקה).
  2. באפליקציה: ⚙️ (למעלה) ← "סנכרון בין מכשירים" ← ללחוץ על הקישור "טוקן GitHub עם הרשאת gist בלבד".
  3. ב-GitHub: לבחור Expiration: No expiration, לגלול למטה ← Generate token.
  4. להעתיק את הטוקן (מתחיל ב-ghp_) ← להדביק באפליקציה ← התחבר. יופיע "מסונכרן ✓".
  5. לשמור את הטוקן במקום בטוח (GitHub מציג אותו רק פעם אחת), ולהדביק את אותו טוקן גם בטאבלט ובמחשב.
🔒 הטוקן נשמר רק במכשירים שלך ומאפשר גישה רק ל-gists (לא לשום דבר אחר בחשבון). אפשר לבטל אותו בכל רגע ב-GitHub. בלי סנכרון: ⚙️ ← גיבוי ידני מאפשר לייצא ולייבא קובץ.

8 המערכת ביומן Google (ווידג׳ט ותזכורות)

אחרי שהסנכרון מחובר: ⚙️ ← 📆 יומן ← הפעל יומן. נוצר יומן חי עם השיעורים של הקבוצות שלך (כולל כיתות ושינויים), הגשות, בחינות ותפילות (אם הפעלת). משם הוא מגיע ל-Google Calendar בטלפון ובטאבלט — כולל הווידג׳ט במסך הבית.

הדרך המומלצת — מתעדכן כל שעה

סקריפט קטן ב-Google (חינם, בחשבון שלך) מעתיק את היומן כל שעה ליומן אמיתי בשם "הסמסטרון", צבוע לפי קורס, עם תזכורות: 15 דקות לפני שיעור, יום ו-3 שעות לפני הגשה, ושבוע, יום ושעה לפני בחינה. ההוראות המלאות נמצאות ב-⚙️ ← 📆 יומן, ובקצרה:

  1. script.google.com ← פרויקט חדש ← להדביק את הקוד מהקישור שבהגדרות ← שמירה.
  2. ⚙️ Project Settings ← Script properties ← CALENDAR_URL = הכתובת מ-⚙️ ← 📆 יומן ← "העתק".
  3. לבחור setup ← Run ← לאשר הרשאות. (במילוי הראשון זה לוקח 2–3 הרצות — זה נמשך לבד כל שעה.)
  4. באפליקציה: ⚙️ ← 📆 יומן ← "הגדרתי את הסקריפט".

הדרך הפשוטה — בלי סקריפט

⚙️ ← 📆 יומן ← "הוספה כקישור" ← Google Calendar. עובד מיד, אבל Google מרענן יומן כזה רק פעם ב-8–24 שעות, ותזכורות מגדירים ב-Google Calendar ← הגדרות היומן ← התראות ברירת מחדל.

9 הגשות מהמודל

במקום להקליד מועדים — מייבאים אותם מהמודל (⚙️ ← 📥 מודל ← ייבוא ידני):

  1. במודל: לוח שנה ← ייצוא לוח שנה ← "כל הקורסים", "אירועים אחרונים וקרובים" ← ייצוא. יורד קובץ .ics.
  2. להכניס אותו לאפליקציה באחת הדרכים:
    • במחשב: לגרור את הקובץ לחלון האפליקציה (או קליק ימני על הקובץ ← "פתח באמצעות" ← שיעורים).
    • באנדרואיד: לפתוח את ההורדות ← לשתף את הקובץ ← שיעורים.
    • או: ⚙️ ← ייבוא מטלות מהמודל.

מטלות חדשות נוספות, מועדים שהשתנו מתעדכנים, מטלות שנמחקו במודל יורדות, ומה שכבר סימנת נשאר. כדאי לחזור על זה פעם בשבוע-שבועיים.

🔔 מרכז העדכונים (הפעמון למעלה): כשיש סנכרון אוטומטי עם המודל, כל שינוי — מטלה חדשה, מועד שזז, מטלה שנמחקה — מופיע שם ונשלח כהתראה. כרגע זה פועל רק אצל מי שהקים את האפליקציה (הבדיקה רצה מהשרת שלו); אצלך הייבוא הידני עושה את אותו הדבר.

10 טיפים קטנים

  • לחיצה ארוכה על האייקון (אנדרואיד) או קליק ימני עליו (Windows) — קיצורים ישירים ל"לעשות", "מערכת", "משימות" ו"בחינות".
  • המספר על האייקון ב-Windows מראה כמה דברים פתוחים. בוחרים מה הוא סופר ב-⚙️. (באנדרואיד מופיעה נקודה רק כשיש התראה.)
  • טאבלט לרוחב / מחשב: "לעשות" ו"משימות" מוצגים זה לצד זה.
  • במחשב — מקלדת: 1–5 מעבר בין לשוניות, N מטלה חדשה, / חיפוש, S סנכרון, ? רשימת הקיצורים.
  • במחשב: ⌃ בפס הכותרת של חלון האפליקציה מעביר את הלשוניות לפס הכותרת — נראה כמו אפליקציה רגילה.
  • 🎨 מראה (⚙️): אוטומטי לפי המכשיר, בהיר או כהה — לכל מכשיר בנפרד.
  • המספר על האייקון: בוחרים ב-⚙️ מה הוא סופר — שיעורים להשלים, הגשות קרובות, בחינות, מפגשים שנשארו היום.
